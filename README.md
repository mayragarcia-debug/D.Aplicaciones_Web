# Módulo de Ventas - API REST

## Descripción

Proyecto desarrollado con Spring Boot para implementar una API REST
orientada a la gestión de un módulo de ventas.

El sistema permite administrar clientes, empleados, categorías,
productos, ventas y detalles de venta mediante operaciones CRUD.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman
- Git y GitHub

## Base de datos

La aplicación utiliza una base de datos MySQL llamada:

`modulo_ventas`

Tablas utilizadas:

- categoria
- cliente
- empleado
- producto
- venta
- detalle_venta
